## 통합하면서 정리한 기준

- JSON/YAML의 초기 Studio 배치, 별도 swap 열, 고정 폭 제안은 현재 통합 편집 카드와 공통 셸로 대체한다. 아이콘 액션·AsyncAPI 예제·진단 footer·복사 피드백은 변환 문서에 모은다.
- OpenAPI의 초기 2행 헤더는 현재 데스크톱 1행 카드형 셸로 대체한다. 형식 메뉴는 편집기 헤더, 내보내기·샘플은 Topbar에 둔다.
- 디자인 시스템의 차수별 이관 순서는 제거하고 토큰/프리미티브/동기화/독립 배포/검증과 Electron·Kotlin 예외를 정리한다. 상세 토큰 값은 정본 README와 CSS를 참조한다.
- API Contract의 설계 당시 Worker 메시지와 카테고리 예시는 현재 protocol.ts와 test-case.ts 기준으로 고친다.
- 클래스 설계서의 MVP 스캐폴딩은 현재 처리 흐름으로, Java 멀티모듈·Kotlin 확장은 프로젝트 지원 문서로 합친다. 기존 소스 분석·잡 처리 ADR은 유지한다.
- 다이어그램 계획의 PNG 크기 제한·해시 충돌 처리·엔진 장애 분류는 현재 구현 보장과 구분한다. 이관 작업에서 해당 기능을 추가하지 않는다.
